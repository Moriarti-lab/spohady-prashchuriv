# default_perk_tree.json

Єдиний дефолтний ассет Древа для редактора (не для гри).

Зараз: **v7.3** (seed 424242) з `tree_v7/out/perk_tree_v73_424242.json`.

Гра й далі вантажить `res://data/perk_tree.json` (v4). Цей файл на неї не впливає.

Підміна без змін коду:
```bash
cp /path/to/new_tree.json data/editor/default_perk_tree.json
```
