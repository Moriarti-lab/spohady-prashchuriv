# Візуалізатор «Древа звитяги» v5

Генератор + живий перегляд у браузері: дерево росте пошарово (коріння →
стовбур → крона → грона → вершина → заповнення), можна перегенерувати з
новим seed і зберегти JSON.

## Запуск

```bash
python3 tools/tree-viewer/viewer_server.py 8734
```

Відкрити <http://127.0.0.1:8734/>. Лише stdlib, без залежностей.

## Що є

- Пошаровий ріст із підльотом камери; пауза, повтор, швидкість 0.5–4×.
- Панорама й зум (колесо / щипок), «Показати все»; підписи з'являються при
  наближенні.
- Клік по вузлу — назва, тип, регіон, опис і бонуси людськими назвами,
  підсвітка його зв'язків.
- Фільтри за регіоном і типом; легенда згортається (на вузькому екрані —
  сама).
- **🎲 Згенерувати** — новий випадковий seed; поле seed + **↻** — конкретний.
- **⤓ JSON** — зберегти поточне дерево; **⤒ Файл** — відкрити будь-який
  `perk_tree.json`; **☰ Журнал** — stdout генератора.
- Футер: вузли, зв'язки, сироти, досяжні, середній ступінь, мін. відстань,
  seed.

`?instant=1` у адресі — показати готове дерево без анімації.

## Як це працює з генератором

Генератор пише JSON у `out/perk_tree_<seed>.json` (через копію скрипта з
іншим `random.seed`), сервер віддає його в браузер. Гра в `data/perk_tree.json`
не чіпається: щоб узяти дерево в гру, натисни **⤓ JSON** або скопіюй файл з
`out/`.

Кожен seed міняє силует: пропорції коріння й стовбура, розхил і глибину крони,
позиції грон та еліпс вершин. Будова (3 корені → стовбур → 3 гілки → грона →
вершини + серце) і формат незмінні.

## Адреси

- `GET /api/tree` — поточне дерево (tree, seed, stats, log)
- `POST /api/generate` — згенерувати; тіло `{"seed": 123}` необов'язкове

## Офлайн

Без сервера сторінку можна відкрити як файл: браузер попросить вибрати
`perk_tree.json` (кнопка **⤒ Файл**). Кнопка 🎲 тоді недоступна.
