# Редактор Древа звитяги v5

Один HTML-файл, без бібліотек і без інтернету. Відкривається на телефоні й на ПК.

## Як користуватись

1. Відкрий `index.html` у браузері.
2. **⇅ JSON → Обрати файл** → `data/perk_tree.json`.
3. Редагуй. Кожна зміна автоматично зберігається в браузері.
4. **⇅ JSON → Завантажити .json** → поклади в `data/perk_tree.json`.
5. `python3 tools/sync_editor_tree.py` — вбудувати дерево в гру.
6. `bash tests/run_all.sh` — перевірки.

## Що є

- Полотно на SVG: панорама, масштаб (колесо / щипок), «Показати все».
- Режими: вибір, рух, додати вузол, зв'язати, видалити.
- Мультивибір рамкою й Shift+кліком, перетягування групи.
- Прив'язка до сітки + напрямні по сусідніх вузлах.
- Undo / redo (до 80 кроків).
- Панель вузла: назва, тип, регіон, координати, опис, іконка, **бонуси з
  людськими назвами** («Шкода %: 4» замість `dmg_pct`).
- Пакетні дії: регіон/тип для виділення, вирівнювання, розподіл, дублювання.
- Вкладка «Древо»: назва, коментар, старти класів, регіони й кольори.
- Вкладка «Перевірка»: дублі id, биті зв'язки, недосяжні від стартів, однакові
  описи, вузли без бонусів, занадто близькі вузли.
- Вкладка «Вигляд»: пошук, фільтри за регіоном і типом, крок сітки й прив'язки.
- Мінікарта.
- Довідка з гарячими клавішами (кнопка **?**).

## Гарячі клавіші

`V` вибір · `H` рух · `A` вузол · `L` зв'язок · `Del` видалити ·
`Ctrl+Z` / `Ctrl+Y` · `Ctrl+A` · `Ctrl+S` · `F` показати все ·
стрілки — зсув на крок прив'язки.

## Тест

```bash
npm install jsdom          # один раз
node tools/tree-editor-v5/test.js
```

Тест завантажує справжній `data/perk_tree.json` (922 вузли) у jsdom і перевіряє
рендер, редагування, undo/redo, зв'язки, перевірку, експорт, фільтри й швидкість.

## Чим відрізняється від `tools/tree-editor/index.html`

Старий редактор уміє лише базове: режими, сітка, перевірка, експорт.
Тут додано імпорт, мультивибір, фільтри, мінікарту, редактор бонусів із назвами,
перевірку недосяжності й напрямні. Детальне порівняння трьох редакторів —
[`docs/editors_analysis_2026-11-07.md`](../../docs/editors_analysis_2026-11-07.md).
