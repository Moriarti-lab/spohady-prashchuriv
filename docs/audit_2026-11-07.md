| Що | Стан |
|---|---|
| Архітектура | `aarch64`, Debian 13 (trixie) |
| Godot 4.7.2 (linux.arm64) | рушій запускається, `--version` ок |
| **Редактор Godot** | **падає з SIGSEGV** одразу після ініціалізації теми |
| Godot 4.6.3 | те саме — падіння не залежить від версії |
| Порожній проєкт | теж падає → це **оточення**, не проєкт |
| Xvfb | не стартує: ФС забороняє `link()` для `/tmp/.X98-lock` |
| `libfontconfig1`, `xvfb`, X11/Wayland клієнти | встановлено, не допомогло |

і не бачить ресурсів — гра не стартує (`Identifier "Nauzi" not declared`).
