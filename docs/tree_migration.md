# Міграція Древа звитяги

**Правило (постійне):** при кожній критичній зміні дерева — **один раз** автоматично повернути всі очки перків. Золото й Воду забуття не витрачаємо.

## Що вважається зміною

Актуальне дерево (пріоритет):

1. `user://overrides/tree.json` (пакунок редактора)
2. `user://tree_active/perk_tree.json`
3. `res://data/perk_tree.json` (корабельне)

Ідентифікатор: `PerkTree.tree_id()` =
`meta.tree_version` (або `meta.version_tag`) + `#` + короткий хеш відсортованих `nodes[].id` і `links`.

У сейві героя (SAVE_VERSION **4**, нове опційне поле):

- `tree_version` — рядок, проти якого розподілені `unlocked`.

## Коли спрацьовує повернення

При `GameState.from_dict`:

- немає `tree_version` у сейві, **або**
- `tree_version` ≠ `PerkTree.tree_id()`, **або**
- у сирому `unlocked` є ID, якого немає в актуальному дереві

Тоді:

1. `unlocked = [class_start]`
2. `perk_points = expected_perk_points()` (усі очки з рівня + `bonus_perks`)
3. `notice` з українським поясненням (якщо ще порожній)
4. у сейв пишеться новий `tree_version`

Повторне завантаження того ж сейва після міграції notice не показує й очки не накручує.

## Текст notice

«Древо звитяги оновлено. Відкриті вузли скинуто, усі очки перків повернено — розподіли їх наново. Золото й Воду забуття не витрачено.»

## Що не чіпаємо

Інвентар, наузи, золото, Воду забуття, прогрес локацій, квести. Логіка збереження — лише поле `tree_version`.
