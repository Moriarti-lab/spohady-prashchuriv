# Формат `data/perk_tree.json` (Древо звитяги)

Поточна версія формату: **4**.

## Загальне

```json
{
  "format": "spohady-perk-tree",
  "version": 4,
  "title": "Древо звитяги",
  "comment": "…",
  "regions": [ {"id": "str", "name": "Сила", "color": "#D8574B"}, … ],
  "class_starts": { "druzhynnyk": "s_root", "strilets": "a_root", "volkhv": "f_root" },
  "nodes": [ { "id": "…", "name": "…", "x": 0, "y": 0, "type": "small", "stats": {}, "skill": "", "icon": "", "region": "str", "description": "" } ],
  "links": [ ["id_a", "id_b"], … ]
}
```

| Поле | Обов’язкове | Опис |
|------|-------------|------|
| `format` | так | завжди `spohady-perk-tree` |
| `version` | так | `4` (поточна). Підтримуються також `1`, `2`, `3` для читання старих файлів |
| `regions` | так | три гілки: Сила / Спритність / Віра |
| `class_starts` | так | id стартового вузла кожного класу |
| `nodes[].type` | так | `small`, `notable`, `keystone`, `start`, `core` (`skill` — застарілий, лише сумісність) |
| `nodes[].stats` | ні | словник бонусів (ключі з `PerkTree.STAT_ORDER`) |
| `nodes[].skill` / `mod_skill` / `mods` / `starter` | ні | **застарілі в v3+**. Активні вміння — це предмети-наузи, не вузли Древа |
| `links` | так | неорієнтовані ребра між id вузлів |

## Розкладка v4 (Yggdrasil)

Детермінована геометрія (не випадкові «прогулянки»):

- **Коріння** — одне широке віяло вниз від бази стовбура: радіальні промені з розвилками й поперечними зв’язками. Старти класів (Сила / Спритність / Віра) вбудовані в віяло й виділені, а не три окремі «грудки».
- **Стовбур** — чиста звужувальна колона з 4–5 поздовжніх пасом і регулярними короткими поперечками (без клубків). Ширина ≈ 15–20 % ширини крони.
- **Крона** — великий рівний купол (еліпс): гілки від верху стовбура до плодів, сітка заповнення без великих дір. **Плоди** = notable + кільце малих; ключові вузли й «Серце роду» вгорі.
- Тір за висотою; на стиках регіонів — мікс кольорів (стовбур / внутрішні гілки), зовні — колір класу.
- Зв’язки в грі — криві гілки; у стовбурі товстіші, з відтінком кори.
- Цільовий обсяг: ~700–950 вузлів (форма важливіша за кількість).

## Збереження

При зміні розкладки id, яких більше немає в Древі, повертають витрачені перки гравцеві (міграція при завантаженні).

## Редактор

`tools/tree-editor/index.html` читає/пише той самий JSON. Після зміни `data/perk_tree.json` синхронізуй вбудоване дерево:

```bash
python3 tools/sync_editor_tree.py
```
