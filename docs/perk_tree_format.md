# Формат Древа звитяги (`data/perk_tree.json`)

Гра читає Древо з файлу **`res://data/perk_tree.json`** (у репозиторії — `data/perk_tree.json`).
Редактор **`tools/tree-editor/index.html`** пише рівно цей формат. Гра перевіряє файл при запуску й пише помилки в лог; перевірка формату — у `tests/smoke_test.gd` (розділ «Древо») і `tools/test_editor.js`.

## Як це працює разом
1. Відкрий `tools/tree-editor/index.html` у браузері (телефон або комп'ютер, інтернет не потрібен).
2. Змінюй вузли й зв'язки.
3. Кнопка «⇅ Імпорт / Експорт» → «⬇ Завантажити perk_tree.json» або «⧉ Скопіювати».
4. Поклади файл у `data/perk_tree.json` у проєкті й збери гру (або надішли розробнику).
5. Гра при запуску перевіряє файл тими самими правилами, що й редактор.

Відкрити файл у редакторі: «⇅ Імпорт / Експорт» → вставити JSON у поле → «✔ Застосувати з поля», або «📂 Відкрити файл…».
Після `tools/sync_editor_tree.py` стартове Древо вбудоване прямо в `index.html` (кнопка «↺ Скинути до стартового Древо» повертає його).

## Структура

```json
{
  "format": "spohady-perk-tree",
  "version": 2,
  "title": "Назва (необов'язково)",
  "comment": "Нотатка (необов'язково)",
  "regions": [ { "id": "str", "name": "Сила", "color": "#D8574B", "angle": -90.0 } ],
  "class_starts": { "druzhynnyk": "s_t0", "strilets": "a_t0", "volkhv": "f_t0" },
  "nodes": [
    { "id": "s_t0", "name": "Міцні руки", "description": "Початок шляху.",
      "x": 0, "y": -1100, "type": "start", "stats": { "str": 2 },
      "skill": "", "icon": "", "region": "str" }
  ],
  "links": [ ["s_t0", "s_t1"] ]
}
```

| Поле | Обов'язкове | Опис |
|---|---|---|
| `format` | так | завжди `"spohady-perk-tree"` |
| `version` | так | `2` (поточна); файли версії `1` ще читаються |
| `regions` | ні | області для підписів і кольору: `id`, `name`, `color` (`#RRGGBB`), `angle` (градуси, куди дивиться підпис) |
| `class_starts` | так | вузол старту для кожного класу: `druzhynnyk`, `strilets`, `volkhv` |
| `nodes[].id` | так | унікальний, лише латиниця, цифри, `_`, `-` |
| `nodes[].name` | так | назва українською |
| `nodes[].description` | ні | пояснення (показується в панелі) |
| `nodes[].x`, `y` | так | положення, «умовні пікселі», центр `(0, 0)`, `y` вниз |
| `nodes[].type` | так | `small`, `notable`, `keystone`, `skill`, `start`, `core` (розмір і вигляд кружка) |
| `nodes[].stats` | ні | словник «бонус: число», ключі нижче |
| `nodes[].skill` | для `skill` | id навички, яку вузол відкриває |
| `nodes[].icon` | ні | назва файла без `.png` з `art/icons/perks/` або `art/icons/skills/`; порожньо — іконка за типом/областю |
| `nodes[].region` | ні | id області (колір вузла) |
| `nodes[].starter` | ні | `true` — вузол-навичка є **стартовою на вибір** (v2). Лише для `type: "skill"`. Біля `class_starts[клас]` має бути рівно три такі вузли; гравець обирає один безкоштовно |
| `nodes[].mod_skill` | ні | id навички, яку вузол **поліпшує** (v2): гілка поліпшень після вузла-навички |
| `nodes[].mods` | ні | словник поліпшень навички (потребує `mod_skill`), ключі нижче |
| `links` | так | список пар `[id, id]`; зв'язки двосторонні, без повторів і без петель |

### Ключі бонусів (`stats`)
`str`, `agi`, `faith` (характеристики), `hp` (плоске життя), `hp_pct`, `mana_pct`, `mana_regen`, `armor`,
`dmg_pct`, `atk_speed_pct`, `crit_pct`, `crit_dmg_pct`, `cdr_pct` (швидше відновлення навичок), `dr_pct` (зменшення шкоди),
`drop_pct`, `gold_pct`, `hp_regen_pct`, `lifesteal_pct`, `thorns_pct`, `move_pct`, `xp_pct`. Значення — числа (можуть бути від'ємними).

### Поліпшення навичок (`mods`, версія 2)
`dmg_pct`, `cd_pct`, `mana_pct`, `radius_pct`, `range_pct`, `power_pct`, `duration_pct`, `heal_pct`, `count`, `stun`.
Приклад: `{ "mod_skill": "power_strike", "mods": { "dmg_pct": 12 } }` → «Могутній удар: +12% шкоди». Поліпшення діє, коли відкрито вузол.

### Навички (`skill`)
`stribog_dash`, `power_strike`, `arrow_volley`, `element_wave`, `whirlwind`, `piercing_shot`, `ancestral_heal`, `ground_slam`, `shield_bash`,
`iron_wall`, `triple_slash`, `battle_cry`, `rapid_shot`, `arrow_rain`, `hunters_trap`, `wolf_spirit`, `sun_beam`, `ice_shards`,
`fire_wave`, `chain_lightning`, `poison_cloud`, `earth_spikes`, `raven_swarm`, `ancestral_ward`, `ancestors_wrath` (центр).

## Правила гри
- За рівень дається +3 перки; 1 перк = 1 вузол.
- **Стартова навичка.** Новий герой обирає одну з трьох стартових навичок (вузли з `starter`, сусідні зі стартом класу): площа з меншою шкодою, сильний удар по одній цілі з довгою перезарядкою, швидка атака з дорожчим Чаром. Інші стартові вузли не відкриваються прямо зі старту. Решта Древа закрита, доки не обрано.
- Відкрити можна лише вузол, сусідній з уже відкритим. Початкова точка — `class_starts[клас]` (вона відкрита одразу).
- Вузол `skill` дає гравцеві навичку, яку тоді можна поставити у швидкий слот («Навички» у сумці).
- Невалідний файл: гра пише помилки в лог (гра тоді візьме вбудоване запасне Древо — перевіряй файл у редакторі до збирання), редактор — у нижній панелі й не дає застосувати імпорт з помилками.
  Попередження (наприклад «вузол недосяжний») не блокують.
