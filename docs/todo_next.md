## Правки t61 (05.11.2026)
- Древо звитяги переробити у вигляд справжнього дерева знизу вгору: старти класів унизу в корінні, гілки піднімаються по стовбуру до крони/вершини. Чим вище — тим сильніші й корисніші вузли (тірованість по висоті). Переглянути вигляд вузлів і зв'язків (лінії-гілки, а не прямі відрізки).
- БАГ: кнопки дій (Одягнути/Продати/Вплести тощо) з'їжджають униз через довгий опис — закріпити кнопки внизу панелі в УСІХ вікнах (сумка, торговець, Мокрина, наузи, Древо, характеристики).

Зробити: на вкладці «Наузи» обираєш науз → бачиш його гнізда ниток (порожні/зайняті/закриті з рівнем відкриття) → тиснеш гніздо → список сумісних ниток. Також вплітання для наузів, що стоять у гніздах героя.
