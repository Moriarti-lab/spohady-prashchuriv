# Спогади пращурів

Офлайн action-RPG для Android про пам'ять пращурів і богів Київської Русі.
Без реклами, без інтернету, один гравець. Це **пробна версія 0.6.0**.

## Що є у версії 0.6.0
- Усе з **0.5.4** / **0.5.4.1** (ActionBar сумки, Наузи/Нитки, Древо ×10).
- **Древо звитяги v7.3** (~945 вузлів, seed 424242): силует дерева + павутина всередині; міграція `tree_version` з одноразовим поверненням очок ([`docs/tree_migration.md`](docs/tree_migration.md)).
- **Підказки предметів** PoE-стиль: спільний `DescFormat.item_tooltip` для сумки, крамниці, здобичі, наузів, ниток і прев’ю в редакторі; вимоги червоні лише якщо не виконані; картки з авто-висотою.
- **Редактор Спогадів** (окремий APK з PR #4): overrides дерева/теми/розкладки; вбудована генерація v7; pre-release `editor-v0.1.0-test` не чіпаємо.
- **Іконки:** заповнено 6 порожніх path (`w_wand`, `b_robe`, 4 скіли); круглі маски скілів.
- HUD: підменю портрета праворуч від панелі; плашка ворога вище.
- Інструменти: `analyze_*.py`, `tree-viewer/`, `ui-layout-editor/` — [`docs/tree_tools.md`](docs/tree_tools.md).

## Що було в 0.5.4
- Усе з **0.5.3** (Древо Yggdrasil ~945 вузли, Вода забуття, BBCode-описи, повноекранна карта Древа).
- **Сумка на вузькому landscape:** панель дій (Одягти / Продати / «Ще ▾») закріплена внизу правої колонки й лишається у видимій зоні на 1024×473; довгий опис гортається в `DetailScroll`, а не виштовхує кнопки. Спорядження й сумка/скриня теж скроляться за потреби.
- **Древо ×10 за відстанню між вузлами:** координати в `data/perk_tree.json` масштабовано в 10 разів (радіуси й зони дотику — без змін). `ZOOM_MIN=0.012` для огляду; стартовий фокус лишається читабельним (~0.42 на клас). Мінімальна відстань між вузлами перевірена після масштабу.
- **Редактор Древа** (`tools/tree-editor/index.html`): той самий розширений простір, нижчий мінімальний zoom для `Fit`, snap/сітка під новий масштаб; round-trip через sync з `data/perk_tree.json`.
- **Переклади ключів** `radius_pct` / `range_pct` / `duration_pct` (і суміжні) в описах українською через `PerkTree.STAT_TEXT`.
- Регресійні тести layout: `tests/layout_regression.tscn` (1024×473, 1280×576, 854×480).

## Що було в 0.5.3
- **Селище** зі стартовою безпечною зоною і трьома НПС: купець Радим, травниця Зоряна (дає завдання), старійшина Богдан. Вихід — брамою на краю карти.
- **Три бойові локації** з рівнем ворогів, що росте: Ліс, Болото, Руїни. Переходи брамами на краях карти, дороги показують напрямок, покинуті будинки зі скринями й квестовими речами.
- **Міні-боси** в кожній локації: Вовкулака-ватажок, Болотний велетень, Великий інквізитор. Міцніші, довго відроджуються, дають багату здобич.
- **Древо звитяги: ~922 вузли (Yggdrasil v4)**, три області (Сила, Спритність, Віра), 25 навичок, гілки поліпшень після кожної навички, 69 видатних і 9 ключових вузлів, центр «Серце роду» з навичкою «Гнів пращурів». Кожен вузол має опис із числами. Зв'язки між областями біля старту прибрано.
- **Стартова навичка**: кожен клас обирає одну з трьох (площа / сильний одиночний удар / швидка атака).
- **Спорядження**: права рука, ліва рука (щит або одноручна зброя), дворучна займає обидві; голова, руки, тулуб, ноги, 2 персні, амулет. Предмети мають тип слота й рідкість.
- **Торгівля**: продаж речей, купівля в купця (запас оновлюється), ціни в гривнях.
- **Завдання**: журнал, 6 завдань з нагородами (трави для травниці, рушник купця, вовкулака, лист старійшині, примари, інквізитор).
- **Портрет героя** угорі ліворуч відкриває меню: Сумка, Навички, Древо, Завдання, Характеристики, Меню. Вкладка «Характеристики» показує всі показники й навички (активні та пасивні, відкриті й закриті).
- Керування як у MOBA: джойстик, «Удар», **чотири** кнопки навичок (екран «Навички» призначає слоти). Автозбереження, версія збереження 4, старі збереження мігруються (потрібно обрати стартову навичку).
- Створення героя: ім'я, голос Мокоші, благословення одного з шести богів, клас (Дружинник, Стрілець, Волхв).
- **Редактор Древа** — один HTML-файл [`tools/tree-editor/index.html`](tools/tree-editor/index.html), без інтернету. Формат: [`docs/perk_tree_format.md`](docs/perk_tree_format.md). Іконки: [`docs/icons.md`](docs/icons.md).
- **Редактор v5** — [`tools/tree-editor-v5/index.html`](tools/tree-editor-v5/index.html): імпорт/експорт, мультивибір, фільтри, мінікарта, редактор бонусів із назвами, перевірка недосяжності. Див. [README](tools/tree-editor-v5/README.md).

## Як зібрати
Потрібні Godot 4.7.2 з шаблонами експорту, JDK 17 і Android SDK.
```bash
godot --headless --path . --export-debug "Android debug" build/spohady-v0.6.0.apk
```
Налаштування експорту: `export_presets.cfg` (arm64-v8a, підпис debug-ключем, `com.moriartilab.spohady`).

## Тести
```bash
bash tests/run_all.sh                                           # усе разом: гра + редактор Древа
godot --headless --path . res://tests/smoke_test.tscn          # лише перевірка гри без екрана
xvfb-run -s "-screen 0 1280x720x24" godot --path . res://tests/screenshots.tscn -- /tmp/shots  # знімки екранів
```

## Керування на комп'ютері (для налагодження)
WASD або стрілки: рух · Пробіл/J: удар · 1–4: навички (K, L — перші дві) · B або I: сумка · M: карта · Q: зілля життя · E: зілля чару · P або Tab: Древо.

## Структура
`scripts/data` — дані (боги, класи, Древо, вороги, тексти) · `scripts/actors` — герой, вороги, снаряди ·
`scripts/world` — світ · `scripts/ui` — інтерфейс · `scenes` — сцени · `art` — місця для малюнків.
