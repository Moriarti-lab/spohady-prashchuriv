# Спогади пращурів

Офлайн action-RPG для Android про пам'ять пращурів і богів Київської Русі.
Без реклами, без інтернету, один гравець. Це **перша пробна версія (0.1.0)**.

## Що вже є
- Ізометричний вид 3/4 зверху, low-poly, одна локація з Капищем (місце відпочинку й лікування).
- Керування як у MOBA: віртуальний джойстик ліворуч, велика кнопка «Удар» праворуч і дві кнопки навичок.
- Створення героя: ім'я → голос Мокоші → **пробуджена кров** одного з шести богів (Перун, Велес, Стрибог, Дажбог, Мокош, Сварог) → клас (Дружинник, Стрілець, Волхв).
- Три характеристики: Сила, Спритність, Віра (5 + благословення + перки + речі).
- 3 види базової атаки залежно від зброї: удар мечем, стріла, магічна куля зі стихією бога.
- Древо звитяги: 19 вузлів, +3 перки за рівень, 1 перк = 1 вузол.
- Три моторошні вороги Ордену Єдиного: Послушник, Перевертень (перетворюється на звіра), Примара (стріляє, що висмоктує чар).
- Звитяга й рівні. Смерть: відродження біля Капища, −10% звитяги поточного рівня, гривні й речі не губляться.
- Автозбереження (кожні 20 с, при закритті меню, при рівні, при смерті).

## Що поки заглушка
Іконки навичок і перків, портрети, рамки інтерфейсу, звук і музика. Усе це можна просто додати файлами — див. [`art/README.md`](art/README.md).

## Як зібрати
Потрібні Godot 4.7.2 з шаблонами експорту, JDK 17 і Android SDK.
```bash
godot --headless --path . --export-debug "Android debug" build/spohady-v0.1.0.apk
```
Налаштування експорту: `export_presets.cfg` (arm64-v8a, підпис debug-ключем, `com.moriartilab.spohady`).

## Тести
```bash
godot --headless --path . res://tests/smoke_test.tscn          # перевірка без екрана
xvfb-run -s "-screen 0 1280x720x24" godot --path . res://tests/screenshots.tscn -- /tmp/shots  # знімки екранів
```

## Керування на комп'ютері (для налагодження)
WASD або стрілки: рух · Пробіл/J: удар · K або 1, L або 2: навички · P або Tab: Древо.

## Структура
`scripts/data` — дані (боги, класи, Древо, вороги, тексти) · `scripts/actors` — герой, вороги, снаряди ·
`scripts/world` — світ · `scripts/ui` — інтерфейс · `scenes` — сцени · `art` — місця для малюнків.
