# Спогади пращурів

Офлайн action-RPG для Android про пам'ять пращурів і богів Київської Русі.
Без реклами, без інтернету, один гравець. Це **пробна версія 0.2.0**.

## Що є у версії 0.2.0
- Ізометричний вид 3/4 зверху, low-poly, без тіней, спокійна приглушена земля. Одна долина з Капищем, скелями по краях і зачиненою брамою («Шлях закритий»).
- Керування як у MOBA: джойстик ліворуч, велика кнопка «Удар» і **чотири** кнопки навичок. Які вивчені навички стоять у швидких слотах — обираєш в «Навички» (торкнись слота, потім навички).
- Створення героя: ім'я → голос Мокоші → **пробуджена кров** одного з шести богів → клас (Дружинник, Стрілець, Волхв).
- **Сумка** з сіткою для пальців і слотами спорядження (зброя, броня, оберіг, перстень). Зброя змінює вид атаки: меч, лук, магічна куля. Ваги немає.
- **Здобич**: вороги лишають гривні, зілля (життя, чар) і речі з випадковими бонусами чотирьох рівнів рідкості (Звичайний, Добротний, Рідкісний, Заповітний). Підбирається, коли підійти або торкнутись. Зілля — кнопками швидкого доступу. При смерті нічого не губиться.
- **Карта**: міні-мапа в куті, торкнись — велика карта з героєм, Капищем, ворогами й відкритою територією.
- **Древо звитяги**: 91 вузол, три області (Сила / Спритність / Віра), малі, видатні та ключові вузли, вузли навичок. Клас починає у своїй області. +3 перки за рівень, 1 перк = 1 вузол, лише сусідні. Рух і масштаб пальцями.
- **Редактор Древа** — один HTML-файл [`tools/tree-editor/index.html`](tools/tree-editor/index.html), працює без інтернету на телефоні й комп'ютері. Формат: [`docs/perk_tree_format.md`](docs/perk_tree_format.md).
- Три види ворогів Ордену Єдиного: Послушник, Перевертень, Примара. Більше життя в героя й ворогів.
- Автозбереження (кожні 20 с, при закритті меню, при рівні, при смерті). Смерть: відродження біля Капища, −10% звитяги поточного рівня, гривні й речі не губляться.

## Що поки заглушка
Іконок немає в навичок «Вихор», «Пронизливий постріл», «Поклик предків» (текстові кнопки), немає звуку й музики.

## Як зібрати
Потрібні Godot 4.7.2 з шаблонами експорту, JDK 17 і Android SDK.
```bash
godot --headless --path . --export-debug "Android debug" build/spohady-v0.2.0.apk
```
Налаштування експорту: `export_presets.cfg` (arm64-v8a, підпис debug-ключем, `com.moriartilab.spohady`).

## Тести
```bash
bash tests/run_all.sh                                           # усе разом: гра + редактор Древа
godot --headless --path . res://tests/smoke_test.tscn          # лише перевірка гри без екрана
xvfb-run -s "-screen 0 1280x720x24" godot --path . res://tests/screenshots.tscn -- /tmp/shots  # знімки екранів
```

## Керування на комп'ютері (для налагодження)
WASD або стрілки: рух · Пробіл/J: удар · 1–4: навички (K, L — перші дві) · B або I: сумка · M: карта · Q: зілля життя · E: зілля чару · P або Tab: Древо.

## Структура
`scripts/data` — дані (боги, класи, Древо, вороги, тексти) · `scripts/actors` — герой, вороги, снаряди ·
`scripts/world` — світ · `scripts/ui` — інтерфейс · `scenes` — сцени · `art` — місця для малюнків.
